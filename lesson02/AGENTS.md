# AGENTS.md — правила для coding-агента (opencode) в папке lesson02

## Контекст
Учебный проект: агент-помощник преподавателя математики. Папка `lesson02` —
самодостаточный снимок кода на занятии 2. Тема занятия — реестр инструментов:
цикл в `loop.py` не должен знать имён конкретных инструментов.

## Ограничения
- Python 3.10+, менеджер `uv`. Запуск: `uv run agent`, тесты: `uv run --group dev pytest`.
- LLM вызывается только через `requests` в `src/agent/llm.py`. Не добавлять openai SDK,
  LangChain, LangGraph, PydanticAI.
- Не менять файлы вне `lesson02/`.
- Новый инструмент = новый модуль в `src/agent/tools/` с вызовом `register(...)`
  + импорт в `src/agent/tools/__init__.py` + юнит-тест в `tests/test_tools.py`.
  Изменять `loop.py` для добавления инструмента нельзя.
- Инструмент возвращает `str` или `dict`; исключения ловит реестр.
- Описание инструмента (`description`) пишется для модели: когда применять,
  формат аргументов, пример.
- Код и комментарии понятны студенту 3–4 курса, комментарии по-русски.
- Тесты не ходят в сеть: модель подменяется через параметр `chat` в `run_turn`.

## Перед завершением задачи
1. `uv run --group dev pytest` проходит.
2. Если изменилось поведение агента, обновлены `SPEC.md` и `README.md`.
