# Занятие 2. Реестр инструментов

Референс: [s02 — Tool Use](https://learn.shareai.run/en/s02/)

**Цикл не меняется — возможности регистрируются в таблице диспетчеризации.**
В занятии 1 инструмент был зашит в цикл (`if name == "python_eval"`). Теперь цикл
знает только две функции реестра: `tools.schemas()` (что отправить модели) и
`tools.call(name, arguments)` (как выполнить вызов).

```python
while True:
    reply = chat(messages, tools.schemas())
    messages.append(reply)
    if not reply.tool_calls:
        break
    for call in reply.tool_calls:
        messages.append(tool_result(call.id, tools.call(call.name, call.arguments)))
```

Второе важное изменение: **ошибка инструмента возвращается модели как текст**.
В занятии 1 `1/0` ронял ход. Теперь модель получает `Ошибка ZeroDivisionError: ...`
и может исправить вызов.

## Инструменты

| Инструмент | Для каких задач | Что возвращает |
| --- | --- | --- |
| `python_eval` | арифметика, перебор по небольшому диапазону | значение выражения |
| `sympy_solve` | уравнения, системы, неравенства (`real`, `integer`, `natural`, `complex`) | JSON со всеми решениями и их числом |
| `sympy_simplify` | упрощение выражений | упрощённое выражение |
| `z3_check` | логика, целочисленные условия, «наименьшее/наибольшее» | `status`, `solution`, `unique`, `another_solution` |

### Как z3_check доказывает единственность

1. Солвер находит решение `m` (с `minimize`/`maximize` — оптимальное).
2. Во второй солвер добавляются те же ограничения, то же значение цели и условие
   «решение отличается от `m`»: `Not(And(x == m[x], y == m[y], ...))`.
3. `unsat` → других решений нет, `unique: true`.
   `sat` → `unique: false` и второе решение в `another_solution`.
   `unknown` (таймаут 10 с) → `unique: null`.

Для олимпиадных задач это важнее самого ответа: задача с двумя ответами — брак.

## Демо

1. **Рыцари и лжецы (z3).**
   «На острове живут рыцари (всегда говорят правду) и лжецы (всегда лгут).
   A сказал: "B — лжец". B сказал: "Мы с A одного типа". Кто есть кто?»
   Ожидается вызов `z3_check` с `A == Not(B)`, `B == (A == B)` и ответ
   «A — рыцарь, B — лжец, решение единственно».
2. **Система уравнений (SymPy).**
   «У Пети и Васи вместе 10 марок, у Пети на 2 больше. Сколько у каждого?»
3. **Наименьшее число (z3 + minimize).**
   «Найди наименьшее натуральное n > 1, которое при делении на 3, 4 и 5 даёт остаток 1».
4. **Задача с браком.**
   «Сумма двух натуральных чисел равна 10. Найди эти числа».
   Ожидается `unique: false` и сообщение, что у задачи несколько ответов.
5. **Ошибка и самоисправление.** С флагом `-v` попросите что-нибудь сложное в
   `python_eval` — видно, как текст ошибки возвращается модели.

## Известные ограничения (задел на следующие занятия)

- `eval` в `python_eval` и `z3_check`, `parse_expr` в SymPy выполняют код модели
  без изоляции и таймаута → **занятие 3**, песочница и разрешения.
- Агент проверяет ответ, но задачи никуда не сохраняются → **занятие 4**, банк задач.
- Модель сама формализует задачу и сама проверяет — ошибка в формализации
  останется незамеченной → **занятие 5**, независимый проверяющий.
- Нет лимита шагов цикла → **занятие 8**.
