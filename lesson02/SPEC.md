# SPEC — помощник преподавателя (состояние на занятие 2)

## Назначение
Консольный агент, который помогает преподавателю математики составлять
олимпиадные задачи для 5–9 классов. Конечная цель курса: банк задач, где каждая
задача проверена инструментом и подтверждена преподавателем.

## Что умеет сейчас
- Ведёт диалог в REPL, история `messages` хранится в памяти процесса.
- Сам выбирает инструмент для вычисления или проверки ответа.
- Получает ошибки инструментов как текст и исправляет вызов.
- Для задач в z3 сообщает, единственно ли решение, и показывает второе решение.

## Инструменты
| Имя | Аргументы | Результат |
| --- | --- | --- |
| `python_eval` | `expression: str` | строка со значением |
| `sympy_solve` | `equations: list[str]`, `variables: list[str]`, `domain?: real/integer/natural/complex` | `{"kind": "equations", "count", "solutions": [{var: value}]}` или `{"kind": "inequality", "solution"}` |
| `sympy_simplify` | `expression: str` | строка |
| `z3_check` | `variables: {name: Int/Bool/Real}`, `constraints: list[str]`, `minimize?`, `maximize?`, `check_unique?=true` | `{"status", "solution", "objective_value"?, "unique", "another_solution"?}` |

## Контракт реестра
- `register(name, description, parameters, func)` — регистрация при импорте модуля.
- `schemas()` — список описаний в формате OpenAI tools.
- `call(name, arguments_json) -> str` — никогда не бросает исключение:
  неизвестный инструмент, некорректный JSON и исключение в инструменте
  возвращаются строкой, начинающейся с `Ошибка`.
- Результат-словарь сериализуется в JSON (`ensure_ascii=False`).

## Определение «единственного решения» (z3_check)
Решения m и m' различны, если хотя бы одна объявленная переменная принимает
разные значения. При оптимизации сравниваются только решения с оптимальным
значением цели.

## Вызов LLM
- OpenAI-совместимый `POST {LLM_BASE_URL}/chat/completions` с полем `tools`.
- Настройки в `.env`: `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`.

## Не входит в занятие 2
Изоляция выполнения кода, подтверждение действий, банк задач, независимая проверка.
