# ИИ-агенты с нуля: помощник преподавателя математики

Практический курс, в котором ИИ-агент собирается шаг за шагом. На каждом занятии
к одному и тому же агенту добавляется один механизм, и видно, зачем он нужен.

## Что это и зачем

**Агент — это цикл.** Модель отвечает; если в ответе есть вызовы инструментов,
harness их выполняет и возвращает результаты в историю `messages`, и модель
вызывается снова. Когда модель отвечает текстом, ход закончен.

```python
while True:
    reply = chat(messages, tools)
    messages.append(reply)
    if not reply.tool_calls:
        break
    for call in reply.tool_calls:
        messages.append(tool_result(call.id, execute(call)))
```

Всё остальное в курсе — реестр инструментов, разрешения, банк задач, проверка —
слои вокруг этого цикла. Сам цикл почти не меняется.

**Сквозной пример — помощник преподавателя.** Агент помогает составлять олимпиадные
задачи по математике для 5–9 классов. Он не решает задачи «в уме»: каждый ответ
получает детерминированным инструментом.

- **Python** — арифметика и перебор;
- **SymPy** — уравнения, системы, неравенства, упрощение выражений;
- **z3** — логические и целочисленные задачи. Солвер не только находит ответ,
  но и **доказывает, что он единственный**: задача с двумя ответами — брак.

Конечная цель курса — банк задач, где каждая задача проверена инструментом и
подтверждена преподавателем.

**Без фреймворков.** Модель вызывается одним POST-запросом через `requests`, без
OpenAI SDK, LangChain, LangGraph и т. п. Весь механизм агента — несколько сотен
строк, которые можно прочитать целиком.

**Референс:** [Learn Claude Code](https://learn.shareai.run/en/) — 20 разделов
(s01–s20) о том, как устроен агент вроде Claude Code. Занятия курса следуют
первым разделам и переносят их на свою предметную область.

## Для кого

- Студенты 3–4 курса, уверенно пишущие на Python.
- Опыт работы с LLM не нужен. Полезно понимать JSON и HTTP API.

## Как устроено занятие

Каждая папка `lessonNN/` — **самодостаточный снимок** агента на этом шаге, а не
патч к предыдущему. Её можно запустить отдельно, а изменения увидеть так:

```bash
diff -ru lesson02/src lesson03/src
```

В каждом занятии одни и те же файлы:

| Файл | Что внутри |
| --- | --- |
| `README.md` | идея занятия, запуск, демо, что изменилось, известные ограничения |
| `SPEC.md` | что агент умеет сейчас, контракты инструментов |
| `EXERCISES.md` | упражнения «На закрепление» и «Перенеси на свой агент» с критерием готовности |
| `AGENTS.md` | правила для coding-агента (opencode), если код дописывается с его помощью |
| `src/agent/` | код агента |
| `tests/` | тесты без сети: модель подменяется через параметр `chat` |

**Ограничения ведут к следующему занятию.** Раздел «Известные ограничения» в
README каждого занятия — это то, что сломано или не сделано, и ссылка на занятие,
где это будет исправлено.

**Две траектории в упражнениях:**
1. *На закрепление* — эксперименты с учебным агентом.
2. *Перенеси на свой агент* — тот же механизм в своём проекте (викторина,
   генератор отчётов, что угодно), начиная с копии `lesson01`.

## Быстрый старт

**Что нужно:**
- Python 3.10+;
- [uv](https://docs.astral.sh/uv/) — менеджер пакетов и окружений;
- модель с поддержкой tool calling: [OpenRouter](https://openrouter.ai/) (нужен ключ)
  или локальная [Ollama](https://ollama.com/) (ключ не нужен).

**Шаги** (на примере занятия 4, для остальных так же):

1. Склонировать репозиторий и перейти в папку занятия:
   ```bash
   git clone https://github.com/chernyatiev/ai_agents_course.git
   ```
   ```bash
   cd ai_agents_course/lesson04
   ```
2. Создать `.env` из шаблона и вписать ключ в `LLM_API_KEY`
   (для Ollama — раскомментировать блок «Вариант 2»):
   ```bash
   cp .env.example .env
   ```
   Если `.env` уже настроен в предыдущем занятии, его можно просто скопировать:
   `cp ../lesson03/.env .env`.
3. Проверить установку. Первый запуск сам создаст `.venv` и поставит зависимости;
   модель и сеть для тестов не нужны:
   ```bash
   uv run --group dev pytest
   ```
4. Запустить агента. Флаг `-v` печатает каждое сообщение, добавленное в `messages`:
   ```bash
   uv run agent -v
   ```
5. Задать вопрос, например: «Найди наименьшее натуральное n > 1, которое при
   делении на 3, 4 и 5 даёт остаток 1». Выход — `/exit` или Ctrl+D.

У каждого занятия свои окружение (`.venv`), команды REPL и демо — они описаны в
README занятия.

**Если что-то не работает:**

| Симптом | Причина |
| --- | --- |
| `[ошибка harness] HTTPError 401` | неверный или пустой `LLM_API_KEY` в `.env` |
| модель не вызывает инструменты или `HTTPError 404` | выбранная `LLM_MODEL` не поддерживает tool calling |
| `Connection refused` при работе с Ollama | не запущен сервер: `ollama serve` |

## Как переходить к следующему занятию

1. Прочитать в README нового занятия разделы «Главная идея» и «Что изменилось».
2. Посмотреть изменения кода: `diff -ru lessonNN-1/src lessonNN/src`.
3. Скопировать `.env` из предыдущего занятия и запустить тесты.
4. Сделать упражнения из `EXERCISES.md`.
