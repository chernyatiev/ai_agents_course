# Занятие 1. Минимальный цикл агента

Референс: [s01 — The Agent Loop](https://learn.shareai.run/en/s01/)

Агент — это цикл: **модель → инструмент → результат обратно в `messages`**.
Пока в ответе модели есть `tool_calls`, harness выполняет инструменты и снова
вызывает модель. Когда модель отвечает текстом, ход закончен.

```python
while True:
    reply = chat(messages, TOOLS)
    messages.append(reply)
    if not reply.tool_calls:
        break
    for call in reply.tool_calls:
        messages.append(tool_result(call))
```

В этом занятии у агента ровно один инструмент — `python_eval`. Модель не считает
в уме, а записывает вычисление выражением Python.

## Запуск

```bash
cd lesson01
cp .env.example .env      # вписать ключ OpenRouter или переключиться на Ollama
uv run agent              # обычный режим
uv run agent -v           # печатать каждое сообщение, добавленное в messages
SHOW_TOOLS=1 uv run agent -v  # ещё и описание инструментов перед каждым вызовом модели
uv run --group dev pytest # тесты, сеть не нужна
```

Команды REPL: `/messages` — показать историю, `/reset` — очистить, `/exit` — выход.

Многострочное условие задачи можно просто вставить в терминал (macOS, Linux)
или заключить между строками `"""` — так работает везде, включая Windows.

## Демо

```
ты> Сколько трёхзначных чисел делятся на 7?
  {"role": "assistant", "content": "", "tool_calls": [... "sum(1 for n in range(100, 1000) if n % 7 == 0)" ...]}

  {"role": "assistant", "content": "128. Первое такое число 105, последнее 994 ..."}

```

## Известные ограничения (это задел на следующие занятия)

- Ошибка в выражении роняет ход: модель о ней не узнаёт → **занятие 2**.
- Один инструмент зашит прямо в цикл → **занятие 2**, реестр инструментов.
- `eval` не песочница: ограничены только видимые имена, нет таймаута → **занятие 3**.
- Цикл `while True` без лимита шагов → **занятие 8**, восстановление после ошибок.
