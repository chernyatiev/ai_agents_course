# AGENTS.md — правила для coding-агента (opencode) в папке lesson01

## Контекст
Учебный проект: агент-помощник преподавателя математики. Папка `lesson01` —
самодостаточный снимок кода на занятии 1. Код намеренно минимален: цель — показать
цикл агента целиком и без абстракций.

## Ограничения
- Python 3.10+, менеджер `uv`. Запуск: `uv run agent`, тесты: `uv run --group dev pytest`.
- LLM вызывается только через `requests` в `src/agent/llm.py`. Не добавлять openai SDK,
  LangChain, LangGraph, PydanticAI.
- Не менять файлы вне `lesson01/`.
- Код и комментарии понятны студенту 3–4 курса: без метапрограммирования,
  без лишних классов, комментарии по-русски.
- Тесты не ходят в сеть: модель подменяется через параметр `chat` в `run_turn`.

## Перед завершением задачи
1. `uv run --group dev pytest` проходит.
2. Если изменилось поведение агента, обновлены `SPEC.md` и `README.md`.
