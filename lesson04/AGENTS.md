# AGENTS.md — правила для coding-агента (opencode) в папке lesson04

## Контекст
Учебный проект: агент-помощник преподавателя математики. Папка `lesson04` —
самодостаточный снимок кода на занятии 4. Тема занятия — банк задач:
задачи хранятся в `bank/` по одному JSON-файлу, `verified` ставит harness после
повторной проверки (`verify.py`), `approved` — только преподаватель. Песочница и
разрешения из занятия 3 сохранены.

## Ограничения
- Python 3.10+, менеджер `uv`. Запуск: `uv run agent`, тесты: `uv run --group dev pytest`.
- LLM вызывается только через `requests` в `src/agent/llm.py`. Не добавлять openai SDK,
  LangChain, LangGraph, PydanticAI.
- Не менять файлы вне `lesson04/`.
- Новый инструмент = новый модуль в `src/agent/tools/` с вызовом `register(...)`
  + импорт в `src/agent/tools/__init__.py` + юнит-тест в `tests/test_tools.py`.
  Изменять `loop.py` для добавления инструмента нельзя.
- Инструмент возвращает `str` или `dict`; исключения ловит реестр.
- Инструмент, который выполняет строку модели как код, обязан:
  указать `timeout=` в `register(...)` (или сам запускать `sandbox.run_python`)
  и перечислить аргументы с кодом в `permissions.CODE_ARGS`.
- Новое правило «спросить пользователя» — запись в `permissions.RULES` + тест в
  `tests/test_permissions.py`. В `loop.py` правила не писать.
- Нельзя ослаблять ворота 1 (`BANNED_NAMES`, `ALLOWED_MODULES`), чтобы прошёл тест или
  задача: сначала обсудить с преподавателем.
- Тесты не спрашивают клавиатуру: функция `ask` подменяется в `run_turn`/`check`.
- Банк читается и пишется только через `src/agent/bank.py`. Инструменты не принимают
  путей к файлам — только id задачи.
- Не добавлять модели инструментов, которые ставят `approved`, удаляют задачи или
  меняют статус напрямую. Это команды преподавателя в `main.py`.
- Новое поле задачи: старые файлы банка должны продолжать читаться (`record.get(...)`).
- Тесты не трогают настоящие `bank/` и `.agent/`: `conftest.py` подменяет `BANK_DIR`
  и `AGENT_SETTINGS` на временную папку.
- Описание инструмента (`description`) пишется для модели: когда применять,
  формат аргументов, пример.
- Код и комментарии понятны студенту 3–4 курса, комментарии по-русски.
- Тесты не ходят в сеть: модель подменяется через параметр `chat` в `run_turn`.

## Перед завершением задачи
1. `uv run --group dev pytest` проходит.
2. Если изменилось поведение агента, обновлены `SPEC.md` и `README.md`.
